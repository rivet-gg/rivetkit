---
title: "Resource Limits"
description: "Configure bounded VM, process, JavaScript, Python, and WASM resources."
---

Limits are part of the durable actor config and are applied by Core during VM
creation.

<CodeSnippet file="examples/resource-limits/server.ts" />

Every queue, buffer, timeout, and resource collection has a bounded default.
Near-capacity conditions emit `runtime.limitWarning`; exhausted limits fail
with a typed error naming the limit and the field used to raise it.

Replacing limits normally requires a runtime generation replacement. Graceful
process draining during replacement is a separately tracked follow-up.
