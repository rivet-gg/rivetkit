description: "Execute commands, manage long-running processes, and attach terminals."
---

`process.exec` runs a command to completion. `process.spawn` returns a
generation-scoped process ID for `get`, `wait`, `signal`, stdin, PTY
resize, and bounded output replay.

Use a RivetKit connection for live `process.output` and `process.exit`
events. Replay retained output with `process.readOutput` after reconnecting.

Interactive terminals are separate resources under `terminal.open`,
`terminal.write`, `terminal.resize`, `terminal.snapshot`,
`terminal.wait`, and `terminal.close`. Their live events are
`terminal.data`, `terminal.stderr`, and `terminal.exit`.
