title: "Software"
description: "Install immutable .aospkg command packages."
---

The hosted actor accepts a remote HTTPS package source and optional exact
`sha256:<64 lowercase hex>` digest.

<CodeSnippet file="examples/software/client.ts" />

`software.list()` reads the live installed set. `software.uninstall` removes
one package by its digest-derived `packageId`. Installed descriptors are
durable config and are reconciled when the actor wakes.

Packages are cached per process by content digest. URL-to-digest observations
may avoid a repeat download, but the exact bytes are always verified before
projection.

Registry software is not installed from npm. Releases upload digest-addressed
`.aospkg` files and a relative-URL manifest to S3-compatible object storage.
Embedded Core can additionally install a trusted local artifact path.
